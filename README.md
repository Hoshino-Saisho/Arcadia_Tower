# Arcadia Tower · v0.02

2D 塔防游戏 + 启动器 + 模块化关卡编辑器（Electron + React + TypeScript + Canvas）。更新内容见 [CHANGELOG.md](CHANGELOG.md)。

**▶ 在线游玩：https://hoshino-saisho.github.io/Arcadia_Tower/**（网页版只有游戏端，进度保存在当前浏览器；每次推送到 main 会自动更新；手机也可以玩，点「横屏」）

```
启动器（exe / app）
├─ 开始游戏 → 游戏主页
│   ├─ Play → 章节选择 → 关卡选择 → 战斗
│   ├─ 图鉴：全部角色和敌人的数值与技能
│   ├─ 角色设定：用经验书升级角色 · 选择每个角色携带的技能
│   └─ 无尽模式：敌人一波一波不断出现，击败敌人得分，分数换成货币和经验书
└─ 关卡编辑器
   ├─ ① 角色编辑   ID · 颜色 · 图标 · 数值 · 部署冷却 · 攻击方式（物伤/法伤、攻击敌人/队友、目标数）· 升级成长 · 技能 · 角色试用
   ├─ ② 敌人编辑   ID · 颜色 · 3~6 边形外观 · 数值 · 移动速度 · 攻击方式 · 技能
   ├─ ③ 技能编辑   SP（上限/积累方式/速度）· 自动/手动释放 · 增益减益 · 伤害治疗 · 金钱
   ├─ ④ 章节规划   章节顺序 · 关卡数量 · 战斗音乐 · 主页音乐
   ├─ ⑤ 地图规划   输入「章节编号_关卡编号」(如 ZH_1)
   │    ├─ 地图搭建：积木（地面 / 高台 / 出现点 / 基地 / 不可放置）+ 血量金钱 + 通关奖励倍数 + 战斗音乐
   │    └─ 确认 → 敌人路线规划：时间线拼接敌人积木；自动寻路或手动点选路线（可以转圈）；停留点；撤回 / 取消撤回
   ├─ ⑥ 货币编辑   游戏外货币 · 经验书 · 升级经验（基础经验 + 每级增长）· 等级上限 · 基础通关奖励
   └─ ⑦ 无尽模式   规则（波次 / 难度 / 每组数量 / 敌人强化 / 分数兑换）→ 地图搭建 → 敌人路线
```

## 运行

需要 Node.js 18+。第一次先安装依赖：

```bash
npm install
```

| 命令 | 作用 |
| --- | --- |
| `npm start` | 构建并启动桌面版（启动器窗口） |
| `npm run dev` | 浏览器开发模式 http://localhost:5199 （同样读写项目里的 `data/`） |
| `npm run dist:win` | 打包 Windows 便携版 exe → `release/ArcadiaTower-0.0.2-portable.exe` |
| `npm run dist:win-zip` | 打包 Windows 免安装 zip |
| `npm run dist:mac` | 打包 macOS 应用 → `release/mac-arm64/ArcadiaTower.app` |
| `npm run build:web` | 构建网页游玩版到 `dist-web/`（GitHub Pages 用的就是它） |
| `npm run preview:web` | 本地预览网页游玩版 http://localhost:5198 |
| `npm test` | 无界面测试：寻路（含转圈路线、停留点）、解锁、战斗机制（伤害类型/治疗/技能/增减益/生命上限同步/金钱技能/射程/子弹/范围伤害/停留点/部署冷却/角色等级）、升级经验与通关奖励倍数、负数数值、无尽模式、角色试用、关卡模拟、手机版坐标换算、GitHub 同步逻辑 |

版本号在 `src/version.ts`（显示用，`0.02`）和 `package.json`（`0.0.2`）里，发布新版本时两处一起改。

## 编辑器保存到 GitHub

在关卡编辑器右上角点 **⚙** 设置同步，有两种方式：

- **GitHub API（推荐，打包版 exe / app 用这个）**：填写仓库（`用户名/仓库名`）、分支、数据文件夹（默认 `data`）和访问令牌。
  - 访问令牌：GitHub 网页 → 头像 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token；
    Repository access 选这个仓库，Permissions 里把 **Contents** 设为 **Read and write**。
  - 令牌只保存在本机（Electron 用系统钥匙串加密），不会写进 `data/`，也不会上传。
- **本机 Git**：项目文件夹本身是 Git 仓库时可用（例如在项目里 `npm start`），保存时执行 `git add / commit / pull --rebase / push`，用电脑上已登录的 Git 账号。

同步规则：
- 勾选「编辑器保存后自动上传」后，每次保存（角色、敌人、技能、章节、关卡、全局设置、导入的图标和音乐）几秒内会自动上传，多次保存合并为一个 commit。
- 编辑器顶部显示「已同步 / N 个修改待上传 / 出错」，也可以手动「上传」「拉取」。
- 启动器可以在打开时自动从 GitHub 拉取最新数据（别人上传的关卡、音乐等）。
- 本地和仓库同时修改了同一个文件时：上传会被拒绝并提示先拉取；拉取时会列出冲突，由你选择用仓库版本覆盖还是保留本地。
- 玩家进度 `progress.json`（通关记录、角色设定、游戏外货币、经验书、角色等级）只保存在本机，不会上传。

## 数据保存在哪里

所有内容都是可读的 JSON，编辑器只是它们的图形界面：

```
data/
├─ characters.json        角色
├─ enemies.json           敌人
├─ skills.json            技能库（角色 / 敌人通过技能 ID 引用）
├─ chapters.json          章节（数组顺序 = 解锁顺序）
├─ settings.json          全局设置（主页音乐）
├─ currency.json          货币编辑：游戏外货币、经验书、升级经验、基础通关奖励
├─ endless.json           无尽模式：规则、地图和路线、分数兑换
├─ levels/ZH_1.json       关卡：地图 + 关卡设置（含通关奖励倍数）+ 敌人线（路线、停留点、积木）
├─ icons/                 以后绘制好的图标
├─ music/home/            主页音乐（未进入战斗时播放）
├─ music/battle/          战斗音乐（章节规划 / 关卡设置中选择）
└─ progress.json          玩家进度：通关记录、角色设定、货币、经验书、角色等级（只在本机）
```

- `npm start` / `npm run dev`：直接读写项目中的 `data/`（`npm run dev` 也可以用 `ARCADIA_DATA_DIR` 指定其他目录，例如测试用的副本）。
- Windows 便携版 exe：数据在 exe 旁边的 `ArcadiaTower_Data/` 文件夹；其他打包版本在系统用户数据目录的 `data/`（启动器里「打开数据文件夹」）。
- 环境变量 `ARCADIA_DATA_DIR` 可以指定其他数据目录。

关卡地图用字符保存：`G` 地面、`H` 高台、`S` 敌人出现点、`B` 基地、`X` 不可放置、`.` 空。

## 游戏规则（默认）

- **血量**：敌人的中心点到达基地方块的中心点时扣 1 点血量。血量归零失败；所有敌人都被处理且血量 > 0 即胜利。
- **金钱**：初始金钱 + 可选的每分钟自动回复 + 击杀奖励。部署消耗费用，撤退返还 50%。
- **部署 / 阻挡**：把部署栏里的角色拖到方块上（拖动时时间 ×0.2），松手后战斗暂停，选择「部署」或「取消」后恢复；也可以点卡片再点方块。地面角色放地面、高台角色放高台；地面角色按阻挡数阻挡敌人。
- **部署冷却**：角色编辑中设置（秒，0 = 无）。部署一个角色后，在冷却时间内不能再部署同一个角色（其他角色不受影响），卡片上显示剩余秒数；冷却按战斗时间计算（倍速时更快，暂停时不走）。
- **敌人路线**：自动寻路走最短路线；手动路线可以重复经过同一个方块（转圈、往返）。路线上可以设置**停留点**：敌人第 N 次走到那个方块的中心时停下来，等待设置的秒数再继续（被阻挡时也照常计时；终点基地不能设置）。路线规划中的「↶ 撤回 / ↷ 取消撤回」只撤回当前敌人线的路线修改（路线、出现点、目的地、停留点）。
- **伤害类型**：物伤 = 攻击 − 物抗（无视法抗）；法伤 = 攻击 × (1 − 法抗%)（无视物抗）；两者至少为攻击力的 5%。真伤无视物抗和法抗。
- **射程（按方块）**：以单位所在方块为中心，方块中心距离不超过射程的方块都在射程内（1 = 十字，1.5 = 3×3，2 = 13 格，2.5 = 5×5 去掉四角）；目标站在射程方块上才会被攻击。技能的半径也按方块计算。
- **攻击方式**：
  - 默认攻击（子弹）：向目标发射子弹，命中时结算；每次攻击的目标数可设置，`-1` = 射程内全部。
  - 范围伤害：不发射子弹，每次攻击同时对射程内全部攻击对象立即造成伤害。
  - 两种方式都可以攻击敌人或攻击队友（攻击力为负数 = 治疗），普通攻击可以附带增益 / 减益（治疗时作用在被治疗的队友身上）。
- **技能**：每个技能单独积攒 SP —— 「攻击成功」（每次攻击敌人或队友）或「自动积累」（每秒）；SP 满后自动释放或手动释放（点击场上的角色 → 释放技能）。持续期间不积累 SP。敌人的技能总是自动释放。
- **增益 / 减益**：修改生命上限、攻击、物抗、法抗、攻击间隔、范围、目标数、阻挡数、移动速度、每秒回复（负数 = 持续伤害），固定值或百分比，数量不限，可以同时有增益和减益。同一来源再次施加会刷新时间。
  施加改变生命上限的效果时，当前生命同步改变同样的数值（100 上限 / 40 生命 +20% → 120 / 60）；上限降低不会直接致死（最少 1 点）。
  效果结束时当前生命不变，只是不超过新的上限（120 / 60 → 100 / 60；120 / 120 → 100 / 100）。
- **金钱技能**：技能效果「金钱」= 释放时立即获得 + 持续期间每秒获得（负数 = 消耗）；施放者离场后停止；敌人释放时玩家失去金钱。
- **缓速**：选中部署卡片或场上的角色时，时间流速 = 当前倍速 × 0.2（3 倍速时为 0.6 倍）。
- **解锁**：上一章节全部通关后解锁下一章节；上一关通关后才显示下一关。编辑器中的「试玩」不受限制，也不记录进度。
- **通关奖励**：每次通关（包括重复通关）都获得游戏外货币（默认名称「金币」，和战斗里的「金钱」不同）和按概率掉落的经验书。「货币编辑」中设置的是基础奖励（1 倍）；每个关卡在关卡设置中设置「通关奖励倍数」：本关奖励 = 基础奖励 × 倍数（货币和经验书的数量都乘以倍数，掉落概率不变；小数的数量按概率取整，例如 4.5 本 = 一半机会 4 本、一半机会 5 本）。关卡选择中显示奖励（掉落可以显示精确数值、概率等级或不显示）。试玩不获得奖励。
- **角色升级**：在「角色设定」中给角色使用经验书，每本增加固定经验，并消耗一定的货币。1 级升 2 级需要「基础升级经验」（全部角色通用，默认 100），之后每一级 = 上一级 × (1 + 每级增长)（默认增长 0.75，即 100 → 175 → 306 → 536 …），到等级上限为止。
  每升 1 级，角色的生命 / 攻击（治疗角色 = 治疗量）/ 物抗 / 法抗增加角色编辑中「升级成长」的数值；没有设置的角色默认每级增加基础数值的 5%。战斗中使用升级后的数值。
- **重置进度**（游戏主页）：清空通关记录、货币、经验书、角色等级和无尽模式成绩，保留携带的技能设定。
- **负数数值**：编辑器里有意义的数值都可以设成负数：
  - 角色：费用（部署时获得金钱，撤退时扣回一半）、攻击力（攻击队友时 = 治疗）、物抗 / 法抗（受到更多伤害：物伤 = 攻击 − 物抗，法抗 −100 = 两倍法伤）、升级成长（每级减少；生命最少 1，攻击 / 治疗量最少减到 0）；
  - 敌人：攻击力、物抗 / 法抗、击杀奖励（击败时扣除金钱）、无尽模式的分数和难度；
  - 关卡：每分钟回复（金钱随时间减少，最少为 0）；技能：增益减益、伤害治疗、金钱；无尽模式：每波难度 / 组数 / 数量 / 生命 / 攻击的增加。
  - 增益减益规则不变：原来是正数的物抗 / 法抗，减益最多降到 0；物抗 / 法抗本身是负数时，百分比按绝对值计算（+30% 总是让抗性变高）。
  - 不能设成负数的：生命值、攻击间隔、范围、阻挡数、部署上限 / 冷却、移动速度、体型、技能 SP / 持续时间 / 半径、地图尺寸、关卡数、敌人数量 / 间隔 / 时间、停留时间、等级 / 经验 / 经验书、掉落概率 / 数量、奖励倍数、出现位列等（负数没有意义或会让游戏无法进行）。
- **角色试用**（角色编辑右侧「▶ 角色试用」）：在训练场里试用正在编辑的角色（用编辑中的数值，不需要先保存）。中间是一条地面通道，只有一个来回移动的敌人（默认是不攻击的训练假人，可以换成任意敌人），试用的角色一开始就在场上，也可以撤退或再部署其他角色；
  可以「刷新血量」（敌人回满，被击败时立即重新出现）、「停止移动」、调整全部角色的等级，上方显示伤害 / 治疗总量和每秒数值。敌人被击败后 1.5 秒重新出现。
- **颜色描边**：技能名字、货币等用自定义颜色显示的文字会自动加描边（深色加浅色描边），黑色等深色的角色 / 敌人图形和颜色点也有浅色描边，在深色界面上也看得清。
- **无尽模式**（编辑器「⑦ 无尽模式」，在游戏主页进入）：
  - 敌人一波一波不断出现，没有胜利；基地血量归零或主动「结束挑战」时结算。
  - 当前难度 = 起始难度 + (波次 − 1) × 每波增加。只出现「敌人难度」不超过当前难度的敌人（难度越低越早出现），越接近当前难度的敌人出现得越多。
  - 每波的组数逐渐增加；每组是一种敌人，数量 = 敌人的「出现位列」× 每位列数量（每波还会增加），组内间隔 = 出现位列 × 每位列间隔，所以位列越低，每组越少、间隔越短。每组从地图的敌人线中随机选一条路线（时间线里的积木是额外固定出现的敌人）。
  - 每波敌人的生命 / 攻击按百分比增加。
  - 击败敌人获得「敌人编辑」中设置的分数；结束时每满 N 分换 M 个货币 / 经验书（无尽模式编辑器中设置），并记录最好成绩。试玩不记录成绩、没有奖励。
  - 敌人没有设置无尽模式数值时按生命值估算：分数 = 生命 / 100，难度 = 生命 / 500，出现位列 = 1000 / 生命（1~5）。

## 图标与音乐

- 图标：角色 / 敌人编辑中「选择图片…」会复制到 `data/icons/`；没有图标时显示颜色圆形 / 多边形。建议 256×256 透明背景。
  上传后在图片上点击 / 拖动选择**中心点**（对齐到圆形 / 多边形的中心），滑块调整缩放（保存为 `iconCenter`、`iconZoom`）。
- 音乐：支持 mp3 / ogg / wav / m4a。可以在章节规划中「导入音乐…」，也可以直接上传到 GitHub 仓库的 `data/music/home/`、`data/music/battle/` 后点「拉取」。
  示例音乐 `sample_home.wav`、`sample_battle.wav` 是程序合成的占位音乐，可以随时删除。

## 代码结构与扩展点

```
electron/              主进程（启动器、窗口、数据目录、GitHub 令牌加密保存）、preload、本机 Git 同步
src/core/              数据层：类型、默认值与旧数据兼容、属性与伤害公式、说明文字生成、寻路、解锁规则、存储、GitHub 同步
src/game/              战斗引擎（纯逻辑，可在 Node 中测试）、攻击方式注册表、渲染器、图标与音乐
src/ui/                启动器、游戏页面（主页 / 图鉴 / 角色设定 / 战斗）、编辑器各模块
scripts/sim-test.ts    战斗与关卡测试；scripts/sync-test.ts GitHub 同步测试（模拟 API）
```

- **新方块类型**：`src/core/tiles.ts` 的 `TILE_TYPES`。
- **新的特殊攻击方式**（溅射、链式等）：在 `src/game/attacks.ts` 注册新的行为，角色 / 敌人的 `attackType` 选择它。
- **新的可修改属性**：`src/core/stats.ts` 的 `STATS` + `src/game/entities.ts` 的基础属性。
- 读取旧数据时缺少的字段会自动补默认值（`src/core/defaults.ts` 的 normalize 函数），v0.01 的数据可以直接使用。

## 手机版

## 网页游玩版（GitHub Pages）

`.github/workflows/pages.yml`：每次推送到 main（包括编辑器上传的数据）都会运行 `npm run build:web`，把 `dist-web/` 发布到
https://hoshino-saisho.github.io/Arcadia_Tower/ 。网页版直接打开游戏主页，没有启动器和编辑器；关卡、角色、音乐等数据随网站一起发布，
玩家进度和角色设定保存在玩家自己的浏览器里。

## 关于 Windows exe

`npm run dist:win` 可以在 macOS 上直接打出 Windows 便携版 exe（未签名，第一次运行时 SmartScreen 可能提示「未知发布者」，点「更多信息 → 仍要运行」）。
exe 目前使用 Electron 默认图标：在 mac 上打包需要 `"signAndEditExecutable": false`；以后在 Windows 上打包时改成 `"signExecutable": false` 并在 `build.win.icon` 指定图标即可。
